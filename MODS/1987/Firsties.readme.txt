Short: Some of the first modules ever (1987-1988)
Type: mods/misc
Uploader: tive@vipunen.hut.fi (Timo Vehmaa)

I found these songs (the old trackers couldn't save modules, only ST songs)
from ancient disks and converted them into modules. I needed only one
sampledisk (the original ST-01) to do this since back then it was the only
sampledisk around and everybody used it. Note that I didn't destroy any
comments by the authors since these songs didn't have -any- comments, only
names of the samples.

Includes classics like:
Amegas, Crystalhammer, Demons Soundtrack, Jackdance, Ralleymaster, Sleepwalk,
Sll1, Nothing, Blue Shaddows and much more!

From Authors like:
Karsten Obarski, Frog/D.O.C., A. Starr, SLL

Note that these modules sound bit unpolished by today's standards but some
of the melodies are very nice. Maybe someone could do 1994 remixes? :-)
